# 产品分层与成本模型 v0.1

> 全部金额为**估算**，按 1000 台批量、不含研发摊销与认证费用。正式报价需按实际选型询价。
> 定位：3–5 年以上老车（机械钥匙电门锁）的智能化改造。

## 一、产品矩阵（模块化组合）

产品拆成两块**可独立售卖**的模块，叠加即为打包款：

| SKU | 建议零售 | 内容 | 能否独立卖 |
|---|---|---|---|
| 基础款 | ¥69 | 车辆层基础：BLE 通电 + 自定义音效 + 震动 | 能 |
| 交互款 | ¥269 | 车头屏 + 宠物 + 大模型对话 | 能，需网络 |
| 车辆进阶 | ¥299 | 4G + GPS + 电池仓防盗 + RGB | 能 |
| 打包款 | ¥599 / ¥699 | 交互款 + 车辆进阶 | — |

### 价格必须错开

原方案「交互 ¥299」与「车辆进阶 ¥299」同价，用户会卡在「我花 299 买屏还是买防盗」的对比上。
**交互款定 ¥269，车辆进阶保持 ¥299**：两者不构成直接比价，且 ¥269 更贴近 AI 玩具的心理价位。

### 组合时的两个工程前提

**① 电源必须统一。** 屏 + WiFi + 音频待机是几十 mA 量级，比车辆模块高一个数量级。两块板各自独立待机，铅酸电瓶一周就干。必须由车辆模块的高边 MOS 给屏控电（ACC 才上电），或屏自己做运动唤醒 + 深睡。

**② 冷启动要遮住。** 屏从断电到可用需 3–5 秒（WiFi 连接 + LVGL 初始化）。插钥匙后要有开机动画盖住这段时间，否则用户第一印象是「这屏卡」。

### 每档一句话说清

- ¥69 —— 不用掏钥匙
- ¥269 —— 车头有个会说话的伴
- ¥299 —— 知道车在哪、被动了会告警
- ¥599 —— 两件事都干了

四档不重叠，这是产品矩阵成立的判据。

## 三、安装方式：决定渠道愿不愿意卖

老车市场，门店师傅不会拆车壳。**必须做成「T 型转接、不剪线」**：

1. 拔掉原车电门锁插头
2. 中间串入模块的 T 型转接
3. 贴 NFC 贴纸 / 扫码绑定

全程 3–5 分钟，可逆（拆掉即恢复原状）。这是老车市场的生死线——剪线安装会让 80% 的门店拒绝。

代价是转接端子要通用。建议做「通用插簧 + 快速接线夹」组合，牺牲一点规范性换通用性，配套一张车型对照表。

## 四、安全设计（三条红线）

### 1. 不做物理锁，只做通电

3–5 年老车是机械钥匙拧电门锁，**没有电控锁机构**。所谓蓝牙开锁，实际是**并联一个开关跨接在钥匙开关两端**，吸合即等效拧钥匙。

- 没有「落锁」，断电后车仍可推行
- 想真正锁住只能靠：电子刹车（短接控制器刹车线，电机反拖）或加装电磁锁（¥40+，超预算）
- **必须保留原车钥匙**，模块是「第二把钥匙」而非替代

### 2. 用 MOS，不用继电器

电门锁线电压 = 电池电压（**48–72V 直流**）。普通车用继电器触点额定 30VDC，72V 直流断开时会拉弧、**触点粘死**——粘死即「关不掉」，车一直通电。

- 用 MOS（IPP80N06 等耐压 ≥80V）+ 光耦隔离，无机械触点，成本 ¥5
- **绝不接控制器主电源那根粗红线**（几十安培），只接电门锁细线（<3A）
- 触点两端加续流二极管 + RC 吸收

### 3. 欠压保护（最容易变成投诉的一条）

模块需常电才能蓝牙开锁。老车铅酸 48V 12Ah = 576Wh：

| 待机电流 | 理论放干 | 实际（含自放电与老化） |
|---|---|---|
| 10mA | 50 天 | **2–3 周就打不着** |
| 1mA | 一年 | 可接受 |

必做两件事：
- 降压方案选静态电流 <100µA 的型号（多数 buck 静态 1–5mA，是亏电主因）
- **电压低于阈值自动切断**，宁可功能停摆，也不能把用户电瓶放干

## 五、商业模式上要提前定的两件事

**流量成本。** 进阶款卖断 + 终身免流量 = 每台每年亏 ¥20–30。建议「首年免流量，次年 ¥36/年」或与运营商谈流量池。这条要在定价时就算进去。

**升级路径。** 基础款同一块 PCB 预留 4G / GNSS 焊位，用户后期可加钱升级，不必重买。基础款的战略价值不是赚钱，是**装机量**——有装机量才有小程序用户、才有进阶款转化漏斗、才有后续增值空间。

## 六、备选：基础款换 BLE 专用芯片

基础款只需蓝牙，不需要 WiFi。可考虑 **CH582M**（沁恒，BLE 5.3，RISC-V，约 ¥5–6）：

| | ESP32-C3 | CH582M |
|---|---|---|
| 单价 | ¥10 | ¥5–6 |
| 待机 | 深睡 ~5µA，BLE 广播平均 mA 级 | 深睡 0.3µA，更适合常电场景 |

## 九、交互模块专项风险

### 1. 网络是生死问题，必须现在定

ESP32-S3 只有 WiFi / BLE，没有 4G。¥269 独立卖，装到车头之后靠什么上网？

| 方案 | 体验 | 成本 | 判断 |
|---|---|---|---|
| 手机热点 | 每次上车手动开热点，耗电，用户不会做 | 0 | 不可行 |
| BLE 透传走手机网络 | 免手动，但音频流延迟 +200–500ms，iOS 后台受限 | 0 | 可做，需实测 |
| 屏内建 4G Cat.1 | 最干净 | +¥35 物料 + 流量费 | 推荐，涨价到 ¥399 或用 4G 子板选配 |
| 改 WiFi 场景 | 主打「家里 / 停车 / 公司」用 | 0 | 只能作为补充故事 |

**建议**：¥269 版内建 WiFi，官方口径是「有 WiFi 就全功能」；同时提供 **4G 子板选配 +¥120**，把网络决策交给用户，不打乱主价格锚点。千万别在宣传里承诺「随时随地都能聊」而不解决网络。

### 2. AMOLED 装在车头的高温风险

夏季车头暴晒，密闭壳内温度可到 60–70°C。AMOLED 长期高温会加速亮度衰减、出现残影。

- 固件必须读板载温度（AXP2101 / 内部温度传感器），**超 60°C 自动降亮度、超 70°C 息屏**
- 结构上做遮阳檐 + 金属背板散热，别用全封闭塑料壳
- 停车超过 10 分钟自动息屏，人来/钥匙上电再唤醒

这条不做，一年后会有大量「屏幕发黄、有残影」的售后。

### 3. 车头安装的三个现实约束

- **固定**：不能用双面胶（高温脱落、震动）。要卡箍 + 支架，适配管径 22/25/28mm 三种
- **防水**：微雪板不防水，必须自己做壳，IP65 起，Type-C 口要带胶塞
- **防拆**：屏比车辆模块贵得多，**被偷的概率更高**。要螺丝防盗（Torx）+ 与车辆模块绑定（拆下即锁机，需小程序解绑）

### 4. 宠物怎么养才不腻

纯挂机宠物看两天就腻，留存几乎为零。唯一的护城河是**用车辆数据喂养**：

| 数据 | 宠物反应 |
|---|---|
| 电量 | 低于 20% 宠物「饿」，会喊你充电 |
| 车速 | 骑太快宠物「喘」，骑稳了夸你 |
| 里程 | 攒够里程宠物「长大」、解锁新形态 |
| 久不骑 | 宠物「想你」，开机第一句是这个 |
| 天气/时间 | 早上问早，下雨提醒带伞 |

这套玩法别人抄不走，因为它依赖车辆层数据和长期使用记录。商业化可做宠物皮肤内购、里程兑换，但**别做成氪金养成游戏**——老车用户群对这套极度反感。

### 5. 上市顺序建议（与直觉相反）

原计划是先做车辆层。但从工程风险看，**交互款应该先出**：

| | 交互款 | 车辆层 |
|---|---|---|
| 依赖车型适配表 | 不需要 | 需要（最重的活） |
| 需要实测车 | 不需要 | 需要 |
| 现在能否出货 | 微雪板已到手，小智固件已跑通 | 要等实测与打样 |
| 毛利 | 63%（¥95 卖 ¥269） | 基础款仅 35% |

**交互款先跑，验证「车主愿不愿意为 AI 交互掏钱」这个最不确定的假设**；车辆层并行做实测，等交互款的需求信号回来再决定投入力度。

## 十、渠道毛利与变现模型

### 1. BOM 20–30 与出厂成本 40 的差额

散件采购价通常是**纯电子件**：模组、传感器、喇叭、MOS、阻容。以下不计入：

| 遗漏项 | 量级 |
|---|---|
| 外壳（注塑 / 型材） | ¥5–7 |
| 灌封胶 / 密封圈 | ¥1–2 |
| 线束 + 接插件 + T 型转接 | ¥4–6 |
| 包装 + 说明书 + 贴纸 | ¥1.5 |
| 烧录 + 功能测试工时 | ¥1–2 |
| 不良率（3% 计） | ¥1 |

**实际出厂成本约 ¥38–42**，比 BOM 高 60%。定价必须按 40 算，不能按 25 算。

### 2. 渠道分成

两轮车后市场是渠道生意，门店装一台要赚 30% 左右，否则不推。

| 零售价 | 出厂成本 | 门店分成 | 你的净利 | 净利率 |
|---|---|---|---|---|
| ¥69 | ¥40 | ¥20 | ¥9 | 13% |
| ¥88 | ¥40 | ¥25 | ¥23 | 26% |

**结论：¥69 只能做首销活动价，日常价必须站 ¥88。** 13% 的净利率摊不动研发、售后和退货。

### 3. 音效付费这个模型要改

原设想「开机声音 ¥1–2 一首」，有三个问题：

1. **版权**。卖音效等于卖音乐作品，需要授权。用户上传流行歌曲当开机音，平台要担责。只能卖自有/已授权音效，用户上传的只留本地不上架。
2. **单价太低**。¥1 的交易摩擦成本（支付流程、决策、退款）几乎等于商品价值，转化率会极低。要做就做**音效包 ¥6.6 / 10 首**，或 ¥19.9 年度会员（全部音效 + 每月更新）。
3. **抑制传播**。你会把「换音效」拍成短视频引流，收费反而掐死这个传播点。**音效应该免费，它是获客成本，不是收入来源。**

### 4. 更健康的变现组合

| 付费点 | 价格 | 依赖 | 复购 |
|---|---|---|---|
| 音效主题包 | ¥6.6 | 基础款 | 一次性 |
| 防盗云服务（轨迹 30 天、报警推送、远程断电） | ¥36/年 | 车辆进阶 | **持续** |
| AI 语音人格包 | ¥19.9/年 | 交互款 | **持续** |
| 宠物皮肤 / 成长加速 | ¥6–12 | 交互款 | 中 |
| 电池健康报告（引导换电，与电池厂分成） | 0 | 需装机量 | — |

**核心是两条年度订阅**：防盗云服务守住车辆进阶用户，AI 人格包守住交互款用户。硬件一次性，订阅才是可持续的。

### 5. 升级路径必须在硬件上预留

「低价用户后续升级」要成立，基础款 PCB 必须**现在**留位置：

- 4G / GNSS 模组焊位（不贴片即降配）
- 屏 FPC 连接器座（不贴即省）
- UART 外部接口排针

成本增加约 ¥3–5，换来的是整个 LTV 模型成立。**如果没预留，所谓升级就是重买，用户会被激怒。**

### 6. 数据是长期资产，但合规要先行

装机量起来后手上有：使用频次、里程、充电习惯、骑行时段、粗略位置。可用于换电导流、UBI 保险、电池回收、二手车估值。

但《个人信息保护法》下，**位置信息属于敏感个人信息，需单独同意**。采集前必须有隐私政策与授权弹窗，不能后补。

## 十一、商业推进节奏

### 1. 决定性变量：单摊日装台数

摊位日成本约 ¥350（场地 + 2 人 + 差旅）。零售 88 出厂 40，每台可分配 ¥48。

**盈亏平衡 = 350 / 48 ≈ 7.3 台／摊／天**

| 日装台数 | 单台摊销 | 单台毛利 |
|---|---|---|
| 5 | ¥70 | −22 |
| 7 | ¥50 | −2 |
| 10 | ¥35 | +13 |
| 15 | ¥23 | +25 |
| 20 | ¥17.5 | +30 |

现场改装 40 分钟一台，加拓客时间，一天最多 8–10 台 → **卡在临界线上，稍有不顺就亏。**

### 2. 所以第一优先级不是铺市场，是把安装压到 5 分钟

这不是靠人努力能解决的，是产品设计问题：

- T 型转接，免剪线、免焊接
- 出厂预配对，扫码即绑，现场不调试
- 单人可完成，不需要第二个人扶车

安装从 40 分钟压到 5 分钟，日装从 8 台变 20 台，单台摊销从 ¥70 降到 ¥17——**整个地推模型才成立。**

### 3. 地推不该是员工，该是分销

| | 员工 | 分销 / 区域代理 |
|---|---|---|
| 成本 | 固定工资 + 社保 + 管理 | 无固定成本 |
| 动力 | 拿死工资，装多装少一样 | 赚差价 + 安装费，多劳多得 |
| 风险 | 全在你身上 | 共担 |
| 扩展 | 10 人管得住，100 人就崩 | 可复制 |

做法：代理以 ¥55 拿货，自己定价卖 88–128 并收安装费。「创业者」要的是区域代理权，不是日结工资。

### 4. 摆摊做样板，门店做规模

摆摊受城管、天气、位置、话术影响，极不稳定，且毕业生不会改装车。

**现成的电动车维修店有位置、有工具、有客流、有信任、会改装**，给 35% 分成天然愿意推。

- 前 1000 台：摆摊，目的是验证产品与安装流程
- 1000 台之后：必须转门店加盟，否则永远长不大

### 5. 模型断点：基础款没有 4G，卖不了云服务

基础款能卖的只有音效包（一次性 ¥6.6）。**没有 4G 就没有远程推送、轨迹、远程控车。**

结论：基础款的 LTV 天花板 ¥6–10，获客成本却 ¥50。它不叫「用户」，叫「线索」。

**所以 KPI 不是装机量，是升级转化率。**

### 6. 唯一要盯的指标

> 每 100 台基础款里，有多少台升级到 ¥200 以上？

| 升级率 | 模型状态 |
|---|---|
| < 5% | 不成立，必须调价或改产品 |
| 8% | 刚打平 |
| 15% | 健康，可加速铺 |

这个数低于 8% 就立刻停手复盘，不要继续铺——**铺得越快，亏得越快。**

### 7. 日活陷阱

蓝牙开锁是 BLE 直连，**不需要打开小程序**。用户没有理由天天开你的小程序，"软件使用越多越值钱"这个假设不自动成立。

要造日活钩子：靠近自动同步 → 推送「今天骑了 12 公里，电还剩 68%」。这需要 App 常驻后台，iOS 限制严格。

现实结论：**基础款的日活注定低，它只做漏斗入口，不要指望它撑平台。** 平台活跃度要靠交互款（有屏、有宠物、有每日交互理由）。

## 十二、精细化产品的三条设计原则

大厂做通用 SKU、用电商卖全国，**结构上做不到精细化**：SKU 越少越好卖、详情页必须写成通用、客服必须标准化、一对一装机不可能。这不是意愿问题，是商业模式决定的，所以是持久的空档。

但精细化有它自己的代价，三条原则必须守住。

### 1. 功能越多，售后越多——每个功能必须能独立降级

硬件的售后点不是相加，是**相乘**：解锁 + 声音 + 震动 + 小程序 + 灯效，任何一处失效用户都会报「坏了」。

**设计原则：每个附加功能失效，核心功能必须还能用。**

| 失效项 | 允许的降级 | 绝不能发生 |
|---|---|---|
| 音效文件损坏 | 退化为默认提示音 | 开机卡死、无法上电 |
| 加速度芯片异常 | 关闭震动告警，其余正常 | 整机进入错误循环 |
| 小程序连不上 | 蓝牙直连照常开锁 | 必须联网才能解锁 |
| 4G 无信号 | 本地功能全部可用 | 上电等网络超时 |
| 屏幕异常（交互款） | 车辆模块独立工作 | 屏坏了车也骑不了 |

另外三条硬要求：

- **看门狗必须有**，且复位后要能恢复到安全状态（不通电）
- **故障要能上报**：设备自己记录错误码，小程序能看到，减少「说不清哪里坏」
- **不要做「必须联网才可用」的功能**——同城用户的网络环境比你想的差

### 2. 本地化内容必须做成可下发的资源包

南宁话音效、本地梗语音包是你的 L3 优势，**但如果写死在固件里，扩张到第二个城市就归零**——因为你不懂柳州话、不懂桂林的梗。

**现在就要定的架构：**

- 音效 / 语音包 / 开机动画全部走**资源包**（独立分区或云端下发），不走固件
- 资源包带版本号、可远程替换、可回滚
- 出厂只带 1–2 个通用包，本地化内容由「城市运营商」自己上传

代价是多写一个资源管理模块，大约两周工作量。**不做这个，第二年想开第二个城市就得重刷全部存量设备。**

### 3. 六轴的价值不在震动，在摔倒检测

「六轴降三轴省 ¥1.5」这个建议要撤回——前提是你真的用它。

- **震动 / 移车检测**：三轴加速度就够，陀螺仪没有价值
- **摔倒检测**：需要加速度突变 + 姿态角变化，**必须六轴**
- **急刹 / 压弯识别**：需要陀螺仪

**摔倒检测是两轮车真正的安全痛点，成本几乎为零。** 触发后小程序推送 + 定位 + 紧急联系人，这个功能的说服力远大于「震动提醒」，而且天然适合拍短视频。

**建议：保留六轴，但把它从「多一个传感器」变成「多一个能讲的卖点」。** 只做震动就浪费了。

### 4. 差异化要往 L3 / L4 走，别停在 L2

| 层级 | 内容 | 可复制性 |
|---|---|---|
| L1 通用功能 | 蓝牙靠近解锁、一个能用的 App | 全国谁都能做 |
| L2 功能组合 | 音效、震动、小程序、防撬动 | 半年内可被抄 |
| L3 本地化内容 | 南宁白话开机音、本地梗语音包 | 只有本地人能做 |
| L4 本地关系 | 维修店网络、社区与骑手群 | 完全抄不走 |

**L2 是入场券，不是护城河。** 大厂半年就能补齐功能清单，但补不了「开机说一句街坊听得懂的话」。

**L3 的成本几乎为零，收益却最高**——这是同等价格下唯一无法被通用品替代的东西。
